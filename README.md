## Что умеет

- **Профили на двух движках.** Camoufox (антидетект-Firefox, бесплатный, движок по умолчанию) и CloakBrowser (антидетект-Chromium; бесплатная сборка или Pro-сборка по лицензионному ключу). Отпечаток у каждого профиля свой и сохраняется между запусками.
- **Местоположение по прокси.** Часовой пояс, язык, координаты и адрес WebRTC берутся из страны выхода прокси при каждом запуске. Язык интерфейса самого браузера по умолчанию совпадает с языком профиля, его можно переключить на язык приложения.
- **Прокси.** HTTP, HTTPS, SOCKS4/5, SSH, Shadowsocks и ссылки VLESS/VMess/Trojan/Hysteria2, а также WireGuard; проверка прокси, массовый импорт.
- **Создание профилей.** Серии из нескольких профилей одним действием, шаблоны настроек, одноразовые профили, группы, теги, заметки, пароль на профиль, корзина.
- **Прогрев cookies (Cookie Robot).** Обход списка сайтов выбранными профилями с паузами и прокруткой.
- **Синхронизатор окон.** Действия в ведущем окне повторяются в остальных (CloakBrowser и Wayfern).
- **Камера.** Профиль CloakBrowser может показывать сайтам видеофайл вместо камеры (нужен ffmpeg).
- **Cookies и расширения.** Импорт и экспорт cookies, расширения из Chrome Web Store и из файлов, назначение на группы.
- **Автоматизация.**
  - API, совместимый с Octo Browser, на `127.0.0.1:58888`: скрипты, написанные под Octo, работают без правок.
  - Собственный REST API с ключом на порту 10108.
  - Подключение Playwright, Puppeteer и Selenium через CDP или WebDriver BiDi.

Облачные функции исходного проекта (аккаунт, облачная синхронизация, облачный Cookie Bot) отключены: всё работает локально, без входа в аккаунт.

## Требования

- macOS на Apple Silicon (M1 и новее).
- Для сборки: Node.js 26, pnpm 12, Rust (stable), Xcode Command Line Tools.
- Для подмены камеры видеофайлом: ffmpeg (`brew install ffmpeg`).

## Установка готовой сборки

1. Открыть `.dmg` и перетащить Antidetect в «Программы».
2. Приложение не подписано сертификатом Apple, поэтому при первом запуске нужно разрешить его в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Если macOS пишет, что приложение «повреждено»:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Antidetect.app
   ```
3. При первом запуске приложение само скачивает движки Camoufox и CloakBrowser и базу геолокации.

Ключ CloakBrowser Pro вводится в «Настройки → Лицензия CloakBrowser Pro»; после этого Pro-сборка докачивается в фоне.

## Сборка из исходников

```bash
pnpm install
pnpm tauri build
```

Готовый образ появится в `src-tauri/target/release/bundle/dmg/`.

Чтобы собрать образ для конкретного человека сразу с ключом CloakBrowser Pro, передайте ключ через переменную окружения. В репозиторий он не попадает, но из такой сборки его можно извлечь, поэтому раздавайте её только тому, для кого она собрана:

```bash
ANTIDETECT_BUNDLED_CLOAKBROWSER_KEY=<ключ> pnpm tauri build
```

Отладочная сборка занимает 11 ГБ и больше; с этими переменными около 3,5 ГБ:

```bash
export CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0
```

Запускайте приложение без `HTTP_PROXY`/`HTTPS_PROXY` в окружении: иначе геолокация профилей определится по чужому выходу.

## Проверки

```bash
pnpm format && pnpm lint && pnpm test
pnpm e2e:smoke
pnpm e2e:ui
pnpm e2e:entities
pnpm e2e:integrations
```

Нативные E2E-наборы запускают приложение без окна в изолированной среде. Сценарии в `scripts/scenarios/` проверяют отпечатки и маршрутизацию на настоящих браузерах через работающее приложение (см. `scripts/scenarios/README.md`).

## Устройство

- `src/` — интерфейс (Next.js, React).
- `src-tauri/src/` — вся логика на Rust (Tauri): запуск браузеров, отпечатки, прокси, профили, API.
- `e2e/` — нативные E2E-тесты.
- `scripts/scenarios/` — проверки на реальных браузерах.
- `donut-sync/` — сервер синхронизации из исходного проекта, сейчас не используется.
- `sdk/` — клиенты REST API на Python и Node.

Подробное описание всего, что изменено относительно исходного проекта, и правила работы с кодом — в [AGENTS.md](AGENTS.md).
